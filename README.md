# COOLBOYDRACO GYM

Учебный проект: фитнес-платформа с тёмной темой (чёрный + золотой), регистрацией и своими тренировками. Данные хранятся в браузере (localStorage).

## Страницы

| Файл | Экран |
|------|--------|
| `index.html` | 01 · Вход |
| `register.html` | 02 · Создание аккаунта |
| `forgot-password.html` | 03 · Восстановление доступа |
| `catalog.html` | 04 · Каталог тренировок |
| `workout.html` | 05 · Тренировка в реальном времени |
| `profile.html` | 06 · Профиль пользователя |
| `settings.html` | 07 · Настройки приложения |

## Как открыть

1. Откройте папку `fitness-platform` в проводнике.
2. Дважды щёлкните `index.html` (или откройте через браузер: ПКМ → «Открыть с помощью»).

Либо в терминале из папки проекта:

```bash
# Python
python -m http.server 8080
```

Затем в браузере: http://localhost:8080

## Структура

- `css/styles.css` — общие стили, сетки, адаптив
- `js/app.js` — вход, регистрация, каталог, создание тренировок, профиль, настройки
- `assets/logo.png` — логотип в шапке

## Навигация

Шапка на всех страницах: **Главная** → вход, **Каталог**, **Профиль**, **Настройки**.  
Формы ведут на логичные экраны (вход → каталог, регистрация → профиль и т.д.).
