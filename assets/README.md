# Картинки проекта

Сейчас в проекте уже лежат **SVG-заглушки** — сайт работает без поиска фото.

## Что можно заменить своими файлами

| Файл | Где видно | Рекомендация |
|------|-----------|--------------|
| `logo.png` | Шапка, аватар в профиле | Логотип зала, 52×52 px и больше |
| `workouts/w1.png` … `w6.png` | Карточки в каталоге, страница тренировки | Свои фото (сейчас подставлены ваши) |
| `workouts/custom.svg` | Свои тренировки | Любая общая картинка |

**Важно:** сохраните то же имя файла (например `w1.jpg` вместо `w1.svg`) — тогда в `js/app.js` в `DEFAULT_WORKOUTS` поменяйте путь `image: "assets/workouts/w1.jpg"`.

## Нужно ли искать картинки самому?

- **Для учебного / демо-проекта** — нет, заглушек достаточно.
- **Для «как в настоящем зале»** — да, лучше свои фото или бесплатные стоки с лицензией:
  - [Unsplash](https://unsplash.com/s/photos/gym-workout)
  - [Pexels](https://www.pexels.com/search/gym/)
  - [Pixabay](https://pixabay.com/images/search/fitness/)

Не используйте чужие фото без разрешения.

## Быстрая замена логотипа

1. Положите файл в `assets/` (например `logo.png`).
2. Во всех HTML замените `assets/logo.svg` на `assets/logo.png`,  
   или переименуйте свой файл в `logo.svg`.
